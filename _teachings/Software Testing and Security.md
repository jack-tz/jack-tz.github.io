## Overview

Software Testing and Security (SWEN90006) is a postgraduate
subject at the University of Melbourne that explores
techniques for testing software systems, identifying
security vulnerabilities, and improving software
quality and reliability.

## Teaching Role

Tutor, Semester 2, 2026.

## Topics

- Software testing fundamentals
- Black-box and white-box testing
- Input partitioning and boundary value analysis
- Control flow and coverage-based testing
- Mutation testing
- Automated testing and fuzzing
- Software security and vulnerability detection
